# FishMarco — 生活俠的小幫手

<img src="assets/logo.png" alt="放大版簡約漸層魚形 Logo" width="160">

Windows 鍵盤／滑鼠自動化工具，以 C#、Windows Forms 與 .NET Framework 製作。支援動作範本、範本組合、多選編輯、拖曳排序及循環執行。

## 建置與執行

在 Windows 執行：

    build.cmd
    FishMarco.exe

使用系統內建的 .NET Framework 4.x C# 編譯器，不需要 NuGet 套件。建置會將 assets/app.ico 嵌入執行檔，供檔案總管、視窗與 Windows 工作列使用；執行時不需要另外攜帶圖示檔。若相同位置的舊版仍在執行，請先關閉再建置覆寫。

## 動作範本

- 支援滑鼠點擊、鍵盤按壓及等待。拖曳十字設定滑鼠位置；鍵盤預設 Space，可直接輸入或「捕捉按鍵」。
- Ctrl／Shift 多選，拖曳排序。雙擊適用欄位可直接修改。
- 右鍵「複製」立即在所選動作下方新增獨立副本；「修改」支援同類型動作的選擇性批次修改；「刪除」移除所選項目。
- 上方「套用至所選動作」將編輯區的完整設定套用到所有選取動作。
- Ctrl+Z 復原動作清單編輯。清單取得焦點時，Ctrl+C／Ctrl+V 複製貼上、Del 刪除；文字編輯中保留文字欄位的快捷鍵行為。
- 動作後等待、循環後等待以秒設定，預設顯示 1.0，可保留至小數點後三位；按住時間以 ms 設定。舊範本的毫秒資料會正確換算。
- 單一動作範本的循環次數不存入範本，程式啟動預設為 0（持續），載入範本不覆寫目前設定。
- Ctrl+S 儲存到目前檔案；尚未儲存過的範本會開啟另存新檔。
- 離開未儲存範本時，可選「確定」放棄修改、「取消」返回，或「儲存並關閉」。取消儲存或儲存失敗時不會離開。
- 右下角「顯示／關閉螢幕點位」切換座標標示。

## 範本組合

加入多個範本，依清單順序執行，例如 A × 2 → B × 3。每列範本的次數須為 1～1,000,000。

- 支援 Ctrl／Shift 多選、拖曳排序、Ctrl+C／Ctrl+V 及 Del。
- 上方同列提供「範本循環次數」「循環後等待」「範本切換等待」。選取會帶入數值，修改任一數值會立即套用至所有選取範本的該欄位。
- 可雙擊範本名稱、循環次數或等待時間直接修改。表格不顯示動作數。
- 右鍵「修改範本」切回主視窗的動作編輯頁面，切換前先檢查未儲存變更。儲存後同步更新該組合項目的內容與來源路徑。
- 「範本切換等待」是目前範本全部執行完，到下一列範本之前的等待；最後一列不額外套用此等待。

### 整個組合的循環

執行列左側的「循環次數（0＝持續）」與「循環後等待 (sec)」控制整個清單：

- 預設執行 1 次。設為 2 時，整份 A → B 清單會跑兩遍。
- 設為 0 時持續循環，按 F10 停止。
- 循環後等待只在整份清單完成、準備開始下一遍之前套用。
- 這兩個設定會隨組合檔與自動保存記錄。舊組合檔預設維持執行 1 次。

淺藍色預估時間列計入按住時間、動作等待、各層循環等待、範本切換及一次開始前的 3 秒倒數。持續循環時不顯示有限總時長。實際執行可能因系統排程而稍長。

### 自動保存與來源檔案

關閉範本組合與正常關閉軟體時，自動保存最新狀態到：

    %LOCALAPPDATA%\EvaMacroStudio\last-sequence.json

為保留舊版資料相容性，自動保存仍沿用 EvaMacroStudio 資料夾。下次啟動並開啟範本組合，即可接續使用。自動保存獨立於手動組合檔，不會覆寫手動儲存的組合檔。

組合包含動作副本與來源路徑。來源檔遺失時會跳出警示並在列旁顯示驚嘆號，動作副本仍保留。舊組合若沒有來源路徑，需重新加入範本才能檢查來源檔。

## 顏色掃描小工具

上方「顏色掃描小工具」開啟獨立工具窗，可與動作編輯同時使用。它在螢幕上放一個全透明、可拖曳可縮放的方塊，定時掃描方塊內的顏色，把落在容差範圍內的像素畫成高亮色塊，用來盯住畫面上某個顏色。

### 開始與結束掃描

| 操作 | 快捷鍵 | 行為 |
| --- | --- | --- |
| 開始掃描 | F7 | 自動切到鎖定模式、開始定時掃描，並把工具視窗與主視窗一起縮小 |
| 結束掃描 | F8 | 停止掃描、兩個視窗一起彈回最前並回到編輯模式 |

視窗會還原成掃描前的狀態（一般或最大化），你自己先收起來的視窗不會被動到。掃描方塊不屬於任何視窗，所以兩個視窗縮小後它照樣留在畫面上繼續掃描。

兩個是全域熱鍵，視窗縮小或焦點在其他程式時同樣有效，關閉工具窗即釋放；被占用時狀態列會提示改用按鈕。掃描方塊在工具窗開啟期間一直顯示，方便隨時重新定位。另有「立即掃描一次」可做單次檢查。

F7／F8 只在這個工具窗開啟時被占用 —— 動作範本剛好要送出這兩個按鍵時，請先關閉工具窗。

### 方塊與兩種模式

- **編輯模式**：方塊四周出現藍色邊框，拖曳邊框移動、四角縮放；框內仍然完全透明且可穿透點擊。
- **鎖定並穿透**：只留一圈虛線細框，方塊固定不動，整個視窗對滑鼠等於不存在 —— 點擊與拖曳全部傳到下方程式。座標與大小欄位也一併鎖住，避免誤改。

要移動或改尺寸就切回編輯模式。開始掃描會自動鎖定，一般不需要手動切換。

### 色碼組

「＋ 新增色碼組」每按一次新增一列：

| 欄位 | 說明 |
| --- | --- |
| 目標色碼 | 要找的顏色，支援 `#RRGGBB`、`#RGB`、`RRGGBB` 與英文色名；也可按「吸色」直接取 |
| 高亮 | 不用設定，自動用目標色的對比色，旁邊的色票會顯示算出來的顏色 |
| 容差 | 0～255，每組獨立。以 R／G／B 三個通道中最大的差值判斷 |

高亮色是目標色的對比色（色相轉 180°、彩度拉滿、亮度往反方向拉；接近灰階時改用固定的亮綠或洋紅）。算出來一定和目標色差得很遠，所以顯眼。

色碼輸入到一半不會中斷掃描，該列會暫時跳過並在狀態列說明。最多 20 組。

**順序有意義**：比對由上往下，每個像素只認第一個命中的色碼組。上方那組的容差若已涵蓋下方的目標色，下方就完全不會有命中。兩組顏色相近時，把容差調小、或把想優先看到的放上面。

### 吸色

按每列右側的「吸色」之後：

1. 掃描方塊收起，工具視窗與主視窗最小化讓開
2. 游標旁跟著一個小色票，即時顯示游標下的顏色與色碼
3. 按左鍵取色，Esc 或右鍵取消，之後視窗還原

畫面不會被凍結或蓋住，顏色是在你按下左鍵的那一刻才讀。吸色期間所有滑鼠按鍵都會被吃掉，不會順手在目標程式上點到東西。逾時沒取色會自動取消並還原視窗。

（實作上刻意用最小化而不是隱藏 —— 隱藏會讓視窗從工作列與 Alt+Tab 一起消失。詳細理由與踩過的兩條死路記在 `ColorScan.cs` 的 `ColorPicker` 註解裡。）

### 掃描參數與保存

| 參數 | 預設 | 說明 |
| --- | --- | --- |
| 掃描間隔 | 500 ms | 相位長度的基準，預設值同時是下限；閃爍開啟時實際掃描週期是它的兩倍 |
| 取樣間隔 | 2 px | 每隔幾個像素取樣一次；越大越省 CPU，但越容易漏掉細小色塊 |
| 色塊大小 | 4 px | 命中像素歸進多大的網格，也就是畫出來的高亮色塊尺寸 |

### 亮暗相位

高亮色塊正好蓋在它偵測到的像素上，所以掃描必須在「什麼都沒畫」的時候讀，否則會讀到自己畫的高亮而不是目標色。做法是把每個掃描間隔切成亮、暗兩段，**只在暗相位掃描**。

一個機制兩用：對人來說亮／暗交替就是閃爍，對掃描來說暗相位的畫面是乾淨的。所以「高亮閃爍」這個勾選實際上是在調整暗相位的長度：

| | 亮 | 暗 | 掃描頻率 |
| --- | --- | --- | --- |
| 閃爍開啟 | 一個間隔 | 一個間隔 | 減半（預設 1 秒一次） |
| 閃爍關閉 | 間隔 − 40 ms | 40 ms | 完整（預設 0.5 秒一次） |

開啟閃爍會讓掃描頻率減半，這是必然的取捨：閃爍要慢到看得舒服，暗相位就得夠長。需要高頻掃描就把閃爍關掉。沒有任何命中時畫面本來就乾淨，那一輪會跳過暗相位，所以「什麼都沒找到」既不閃爍也不損失頻率。

**附帶好處：截圖拍得到高亮。** 因為「掃描讀不到自己」是靠那一刻真的沒畫，而不是靠 `WDA_EXCLUDEFROMCAPTURE` 請作業系統隱藏視窗（那個旗標會連使用者自己的截圖一起擋掉）。代價是截圖有機率落在暗相位，拍到沒有高亮的畫面 —— 想穩定截到就把閃爍關掉。

關閉工具窗時自動保存區域、掃描參數、閃爍設定與所有色碼組到：

    %LOCALAPPDATA%\EvaMacroStudio\scan-profile.json

## 測試

    FishMarco.exe --self-test
    type self-test-result.txt

這是 winexe，沒有主控台，所以失敗原因不會印在畫面上。測試失敗時會把例外寫到執行檔旁的 `self-test-error.txt`，成功時寫 `self-test-result.txt`。查問題前記得先刪掉舊的錯誤檔，免得看到過期訊息。

內建測試涵蓋資料儲存、復原、複製貼上、批次編輯、拖曳排序、各層循環與取消、時間估算、自動恢復及嵌入圖示，以及顏色掃描小工具的色碼解析、容差比對、色塊合併、方塊移動縮放、鎖定後拒絕任何拖曳、開始／結束掃描的模式切換、掃描前必先清空畫面的亮暗相位機、自動對比色與目標色的差距、吸色色票定位，以及設定檔保存。測試不會送出實際桌面鍵鼠操作，會在執行檔旁產生結果、測試資料及離屏介面預覽，也不會改寫使用者的自動保存檔。

## 原始碼與資產

- Common.cs：跨檔案共用的三個元件。`OverlayForm` 是五個螢幕覆蓋層的共同底座（視窗樣式、不搶焦點、滑鼠穿透、排除螢幕擷取，Win32 常數都在這裡命名）；`Json` 是序列化的單一入口，統一長度上限；`JsonFile` 是原子寫檔（暫存檔 → 置換）。
- MacroStudio.cs：主視窗、動作編輯、復原與儲存。
- Sequences.cs：範本組合、各層循環、自動保存與時間估算。
- Editing.cs：動作修改、按鍵捕捉、十字拖曳及未儲存警示。
- Interaction.cs：清單多選拖曳、雙擊事件與倒數。
- LiveUI.cs：執行提示、儲存格編輯及程式圖示。
- BatchEditing.cs：選擇性批次修改與秒數格式。
- ColorScan.cs：顏色掃描小工具——螢幕上的方塊、顏色比對、色碼組介面、快照吸色與設定保存。
- FeatureTests.cs：功能與介面測試，包含顏色掃描小工具的 `TestColorScan()`。
- assets/logo.png：放大的藍色漸層魚形、上下魚鰭與白色扳手，無 E 背景的簡約白底 Logo。
- assets/app.ico：16～256 px 多尺寸 Windows 圖示。
- [Logo 生成紀錄](assets/logo-prompt.md)：生成方式與完整提示詞。

較早版本的詳細操作說明保留在 [使用說明.md](使用說明.md)；新版功能以本 README 為準。
